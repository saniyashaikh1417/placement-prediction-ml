# 🎓 Placement Prediction Using Machine Learning

---

## 📌 Project Overview  
This project aims to predict whether a student will be placed or not using Machine Learning techniques.  
It analyzes academic performance and employability factors to build an accurate classification model.

---

## 🎯 Problem Statement  
Student placement plays a crucial role in career development.  
The objective of this project is to develop a machine learning model that can accurately predict student placement based on academic and professional attributes.

---

## 📊 Dataset  
- **Name:** Placement Data Full Class Dataset  
- **Source:** Kaggle  
- **Description:**  
  The dataset contains student-related attributes such as:  
  - SSC Percentage  
  - HSC Percentage  
  - Degree Percentage  
  - Employability Test Score  
  - MBA Percentage  
  - Work Experience  
  - Placement Status (Target Variable)  

---

## ⚙️ Technologies Used  
- Python  
- NumPy  
- Pandas  
- Matplotlib  
- Seaborn  
- Scikit-learn  

---

## 🧠 Machine Learning Models  
- Logistic Regression  
- K-Nearest Neighbors (KNN)  

---

## 📊 Project Workflow  
1. Data Collection  
2. Data Preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Feature Selection  
5. Feature Scaling  
6. Model Training  
7. Model Evaluation  
8. Prediction  

---

## 📈 Results  
The Logistic Regression model achieved good classification performance.  
The model was evaluated using:  
- Confusion Matrix  
- Classification Report  
- Accuracy Score  

---

## 🔮 Prediction  
The trained model predicts whether a student will be:  
- **Placed**  
- **Not Placed**
